La chasse-galerie — network test

Nothing to install: each download carries its own Java.

Windows macOS — Apple silicon (M1 and later) macOS — Intel Linux
  1. Unzip the download and open the folder.
  2. Double-click PLAY (PLAY.bat, PLAY.command or play.sh).
    Windows may say it protected your PC: More info > Run anyway. macOS the first time: right-click PLAY.command > Open > Open.
  3. Menu > Online play: host a game, or type the code a friend gives you.

While Online play is open this build tells the game's server what it sees of your network (the connection test, and whether each player is direct, relayed or reconnecting), so nobody has to send files or screenshots. Nothing else is sent. To play in a browser instead: the page.
